# 机制级权限模型与插件签名

机制是功能与权限的最小单元：全局唯一 ID（形似包名），内含若干钩子；钩子同样有唯一 ID，并指向一段代码文件。插件携带签名：用于辨识系统插件与三方插件，并校验完整性。

权限拦截所有跨机制修改——修改他方参数、钩子或代码文件，以及禁用他方钩子。修改须在安装时声明，并触发确认弹窗（点名将修改的机制，例如“将会修改机制：睡眠”）；未声明的，在运行时运行到该处时弹出授权弹窗兜底。另提供插件冲突检测。注册新参数不需要授权；修改已有参数则按跨机制修改处理。

修改他方行为的推荐模式：禁用原钩子，并在自己的插件中新增一个指向修改后代码文件的钩子；直接改他人代码文件不应作为最佳实践。
