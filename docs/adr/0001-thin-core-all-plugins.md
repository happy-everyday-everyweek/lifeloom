# 核心作为极薄宿主：一切功能皆为插件

核心（宿主）的职责被限定为：插件装载、隔离与卸载，热装载管理，权限校验，事件与钩子调度，参数存储原语，显示与输入外壳。游戏的一切功能——包括基础玩法、实例与动作、判定规则、界面内容、时间系统，乃至存档——全部由插件提供；出厂自带的为系统插件，玩法面向纯自由。

原因：项目目标为“高自由度、高可玩性”——玩家能替换与改造游戏的任意部分来得到自己想要的玩法，而不是在固定玩法上打补丁。

备注：存档由系统插件（存档插件）提供（对齐期间更正，此前曾记为“在核心”）；时间系统同样由插件提供，核心只保留调度原语；跨端流转由独立的跨端流转插件负责（含存档、插件、远程访问等的端间流转）。
