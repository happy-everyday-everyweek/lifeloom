# 权限插件化：核心仅保留极薄闸门原语

权限不是核心的内建功能：放行决策与用户提示由**独立的系统插件（权限插件）**承担。核心只保留极薄原语——插件来源（系统 / 三方）、操作请求、闸门接口、转发器与用户提示通道；核心只转发，不作任何放行决定。

所有非系统插件的跨边界操作（访问他方机制状态、调用他方钩子等，范围随里程碑扩展）一律经闸门转发；闸门未注册时 fail-closed（拒绝）。系统插件与核心自身不受闸门限制。闸门随其注册插件卸载 / 替换而移除。

原因：贯彻“一切功能皆插件”（ADR-0001）。权限策略与提示方式随插件迭代，核心保持极薄；替换权限插件即可升级策略。
