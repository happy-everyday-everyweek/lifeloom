# 构建环境笔记（2026-09-13）

本笔记记录本项目本机开发环境（ARM64 Android 设备上的 Linux 容器）的构建要点，便于后续维护与排错。

## 工具链

JDK 17（/usr/lib/jvm/java-17-openjdk-arm64）。Gradle 使用项目 Wrapper，指向 9.6.1，本机缓存已有该发行版，无需联网。Android SDK 位于 /opt/android-sdk（由 local.properties 指定），使用 AGP 8.9.0、compileSdk 34、minSdk 26。

ARM 设备上 Android 构建的关键点：AGP 默认下发的 aapt2 为 x86-64 二进制，在 ARM64 上无法运行。本机已用 ARM64 版 aapt2 替换 Gradle 模块缓存中 com.android.tools.build:aapt2:8.9.0-12782657 的 jar 内二进制，并同步替换已解压的 transforms 副本。若清理 Gradle 缓存后 Android 构建报 “AAPT2 Daemon startup failed”，参照此方法重新打补丁（ARM64 aapt2 可取自现有 transforms 缓存中已替换的文件）。

## 常用命令

构建桌面端与 Android 调试 APK：

```bash
./gradlew --offline :core:build :shell-desktop:installDist :shell-android:assembleDebug
```

桌面演示：

```bash
./gradlew --offline :examples:demo-plugin:jar
mkdir -p run/plugins
cp examples/demo-plugin/build/libs/*.jar run/plugins/
./gradlew --offline :shell-desktop:run --args="--plugins $PWD/run/plugins --invoke dev.lifeloom.demo.greeting.hello"
```

本机网络不稳定时可加 --offline；依赖缓存齐全时离线构建可用。
